# WS06 – React + Express + MongoDB Blog App

Tässä tehtävässä rakennettiin yksinkertainen full‑stack blogisovellus. Frontend toteutettiin Reactilla ja Vite‑kehitysympäristöllä, ja backend Expressillä sekä MongoDB Atlas ‑tietokannalla. Sovellus tukee blogipostausten luontia, näyttämistä, muokkaamista ja poistamista (CRUD). Frontend ja backend yhdistettiin Vite‑proxyn avulla, ja tietokantayhteys määritettiin .env‑tiedostossa.

Projektin tavoitteena oli harjoitella React‑reititystä, lomakekäsittelyä, REST‑rajapinnan käyttöä sekä MongoDB‑tietokannan yhdistämistä Node.js‑palvelimeen.
